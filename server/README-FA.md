# برنامه تنخواه‌گردانی

## نصب و اجرا
1. Node.js نسخه ۲۲.۵ یا بالاتر لازم است (فقط همین؛ هیچ بسته‌ای نصب نمی‌شود).
2. روی `start.bat` دوبار کلیک کنید (یا `node server.js`).
3. مرورگر: http://localhost:3100  (از شبکه: آدرس IP سیستم + :3100)
4. داده‌ها در پوشهٔ `data/tankhah.db` ذخیره می‌شود. برای پشتیبان‌گیری همین پوشه را کپی کنید. هنگام به‌روزرسانی برنامه این پوشه را بازنویسی نکنید.

## شروع کار
- تنظیمات ← نام شرکت و تهیه‌کننده را بنویسید.
- تنظیمات ← «ورود اطلاعات از اکسل‌های قدیمی» ← فایل‌های اکسل قبلی را انتخاب کنید.
- بانک (بلو) ← فایل صورت‌حساب یا متن پیامک‌ها را وارد کنید.
- هزینه‌ها ← ثبت هزینه ← تنخواه‌ها ← ساخت تنخواه ← نهایی کردن ← Excel/PDF برای دفتر.

## رمز و پورت
- رمز ورود از تنظیمات. پورت: متغیر `PORT`.
