# برنامه تنخواه‌گردانی — نصب روی سرور (جدا از انبار)

این برنامه کاملاً مستقل از Anbar-Server اجرا می‌شود:
| | Anbar | Tankhah |
|---|---|---|
| پوشه | C:\Anbar-Server | **C:\Tankhah** |
| پورت | 8787 / 8790 | **8795** |
| Task Scheduler | Anbar-Supervisor | **Tankhah-Supervisor** |
| دیتابیس | local-server\data | **C:\Tankhah\data** |
| لاگ | Anbar-Server\logs | **C:\Tankhah\logs** |

نصب‌کننده به Caddy، Cloudflared، تنظیمات برق، پورت‌های 8787/8790 و فایل‌های انبار دست نمی‌زند. اگر پورت 8795 را برنامهٔ دیگری گرفته باشد، هیچ تغییری نمی‌دهد و خطا می‌دهد.

## نصب (یک‌بار)
1. Node.js نسخه ۲۲.۵ به بالا (روی سرور شما ۲۲.۲۳ است؛ مناسب است).
2. پوشهٔ `Tankhah` را به `C:\Tankhah` کپی کنید.
3. روی `C:\Tankhah\supervisor\install-autostart.bat` دوبار کلیک کنید (Yes). مثل نصب انبار، رمز ویندوز را بپرسد وارد کنید یا اگر رمز ندارد N بزنید.
4. باید ببینید: `OK: Tankhah answers on http://127.0.0.1:8795` و آدرس شبکه (مثلاً `http://192.168.x.x:8795`).
5. مرورگر ← آدرس بالا ← «تنظیمات»: نام شرکت، رمز ورود، و اکسل‌های قدیمی را وارد کنید.

بعد از هر ریستارت ویندوز خودکار بالا می‌آید و اگر کرش کند ظرف حدود ۴۵ ثانیه دوباره اجرا می‌شود. دستی `start-tankhah.bat` را فقط برای آزمایش اجرا کنید.

## دسترسی از بیرون شرکت (برای اپ اندروید)
گوشی روی Wi‑Fi شرکت با `http://IP-سرور:8795` کار می‌کند. برای بیرون از شرکت، یک آدرس جدا بسازید (مثلاً `tankhah.factor-anbar.online`) که به `127.0.0.1:8795` برسد:
- اگر از Caddy استفاده می‌کنید، در Caddyfile این بلوک را **اضافه** کنید (بلوک‌های قبلی را تغییر ندهید) و DNS همان نام را به سرور بزنید:
  ```
  tankhah.factor-anbar.online {
      reverse_proxy 127.0.0.1:8795
  }
  ```
- اگر Cloudflare Tunnel: در داشبورد Cloudflare یک Public Hostname جدید با مقصد `http://localhost:8795` اضافه کنید.

قبل از باز کردن به اینترنت حتماً در «تنظیمات» رمز ورود بگذارید.

## پشتیبان‌گیری و حذف
- پشتیبان: پوشهٔ `C:\Tankhah\data` را کپی کنید (هنگام به‌روزرسانی برنامه، همین پوشه را بازنویسی نکنید).
- حذف: `supervisor\uninstall-autostart.bat` (فقط تنخواه را برمی‌دارد، داده می‌ماند).
- بررسی: `http://127.0.0.1:8795/api/health` باید `"app":"tankhah"` بدهد. لاگ‌ها در `C:\Tankhah\logs`.
